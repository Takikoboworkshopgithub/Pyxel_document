# Introduction

Pythonとは

シンプルで読みやすく、AI開発やデータ分析、さらにはゲーム制作まで幅広く使われている言語です。

C++との違い

C++は「実行速度」や「メモリ管理」に優れていますが、Pythonは「コードを書く速さ」と「可読性」に特化しています。型の宣言や複雑な記号を省略できるため、直感的にコードを記述できます。

この教材の目標

本教材は、C++の基礎を終えた皆さんが、Pythonの文法を最短で理解するためのものです。
最終的には、Pyxelを使ったゲーム制作へスムーズに移行できることを目指します。

1.1 変数・式

変数宣言

C++
int x = 10;
double y = 3.14;
Python
x = 10
y = 3.14

POINT

  • Pythonは型宣言が不要です。
  • 文末の ;（セミコロン）も不要です。
  • Pythonのint型はほかの言語と違い、どんなに大きな数値でも扱えます。これを任意精度整数といいます。

Pythonの変数はC系の言語と違い、途中で全く違う型の値を入れることも可能です。 

x = 10
x = "hello"  # エラーにならない！

割り算（ / と // ）

C++
5 / 2   // 結果は 2 (整数同士なので切り捨て)
5.0 / 2 // 結果は 2.5
Python
5 / 2   # 結果は 2.5 (通常の除算)
5 // 2  # 結果は 2 (切り捨て除算)

複数代入

Pythonでは、複数の変数にまとめて値を代入する便利な記法があります。

x, y = 1, 2
y, x = x, y  # xとyの値を入れ替える

1.2 条件分岐・繰り返し

if / elif / else

C++
if (x > 0) {
    cout << "positive" << endl;
} else if (x == 0) {
    cout << "zero" << endl;
} else {
    if (x < 10) {
        cout << "very negative" << endl;
    }
    else {
        cout << "negative" << endl;
    }
}
Python
if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    if x < 10:
        print("very negative")
    else:
        print("negative")

POINT

  • {} の代わりにインデント（字下げ）を使ってブロックを表します。
  • 条件式の () は不要ですが、行末に :（コロン）が必須です。
  • else if は elif と書きます。
  • 出力には cout ではなく print() を使います。

forループ

C++
for (int i = 0; i < 10; i++) {
    cout << i << endl;
}
Python
for i in range(10):
    print(i)

Pythonでは range(10) を使うことで、「0 から 9 まで」の連続した数値を生成します。終了条件やインクリメント(i++)を直接書く必要がありません。

TRY

range を使って、1 から 5 までの数字を print で出力してみよう。（ヒント: range(開始, 終了) と書くこともできる）

1.3 リスト

C++の 配列 や vector に相当するのが、Pythonの「リスト」です。

リストの基本操作

a = [10, 20, 30]

# 添字によるアクセス（C++と同じ）
print(a[0])    # 10 が出力される

# 要素の変更（C++と同じ）
a[0] = 100    # a =[100, 20, 30] になる

# 動的に要素を追加（C++の push_back に相当）
a.append(40)    # a =[100, 20, 30, 40] になる

#添え字によるアクセス (後ろから)
print(a[-1])    # 後ろから1番目の意味 40が出力される
print(a[-2])     # 後ろから2目の意味 30が出力される

添字を使ったアクセスはC++と全く同じですが、固定長配列とは異なり append() メソッドを使っていつでも要素を追加できます。

スライス

Python独自の強力な機能が「スライス」です。a[開始:終了] と書くことで、リストの一部を簡単に切り出せます。（終了位置の要素は含まれません） 

a = [10, 20, 30, 40, 50]

# インデックス1から3（4未満）までを取得
print(a[1:4])  # [20, 30, 40]
# インデックス0から2（3未満）までを取得
print(a[:3])   # [10, 20, 30] 最初が0の場合は省略できる
# 逆順に取得 (少し発展)
print(a[::-1])  # [50, 40, 30, 20, 10]

リストのループ (C++でいう拡張for文に相当)

C++
for (int x : a) {
    cout << x << endl;
}
Python
for x in a:
    print(x)
# 10
# 20
# 30
# 40
# 50

TRY

a = [1, 2, 3, 4, 5] から、スライスを使って [2, 3, 4] の部分だけを取り出してみよう。

1.4 関数

関数の定義

C++
int add(int a, int b) {
    return a + b;
}

// 呼び出し
int result = add(3, 5);
Python
def add(a, b):
    return a + b

# 呼び出し
result = add(3, 5)

POINT

  • 関数の宣言には def を使います。
  • 戻り値の型（intなど）も、引数の型も記述する必要がありません。
  • if文などと同じく、末尾の : とブロックのインデントを忘れないようにしましょう。

TRY

引数に名前（文字列）を受け取り、「Hello, [名前]」と表示する関数 greet(name) を作成してみよう。

1.5 Pythonらしい記法

C++経験者が最初に戸惑うかもしれない、しかし慣れると非常に強力なPythonならではの記法をいくつか紹介します。

所属検査（in）

C++で「配列に特定の要素が含まれているか」を調べる場合、ループを回すか関数を使う必要がありますが、Pythonでは in だけで直接記述できます。

a = ["apple", "banana", "orange"]

if "banana" in a:
    print("ある")

リスト内包表記

既存のリストから新しいリストを生成する際、通常の for 文を1行にまとめてスッキリ書くことができます。これは短く書ける魔法の構文というより、「for文の圧縮版」と捉えると理解しやすいです。

通常の書き方
b = []

for x in a:
    b.append(x * 2)
リスト内包表記
b = [x * 2 for x in a]
