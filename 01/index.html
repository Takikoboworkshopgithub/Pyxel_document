# Introduction

Pythonとは

読みやすさを重視した言語です。機械学習やデータ分析、Web開発など大体何でもできる言語。プログラミングで出来そうと思ったらまずはPythonでググってみると幸せになれる

C++との違い

C++は「実行速度」や「メモリ管理」に優れていますが、Pythonは「コードを書く速さ」と「可読性」に特化しています。型の宣言や複雑な記号を省略できるため、直感的にコードを記述できます。

この教材の目標

本教材は、C++の基礎を終えた皆さんが、Pythonの文法を最短で理解するためのものです。
最終的には、Pyxelを使ったゲーム制作へスムーズに移行できることを目指します。

1.1 変数・式

変数宣言と演算

C++
#include <bits/stdc++.h>
using namespace std;

// aのb乗
int pow(int a, int b) {
    int ret = 1;
    for (int i = 0; i < b; i++) {
        ret *= a;
    }
    return ret;
}

int main() {
    int a = 3;
    int b = 2;
    double pi = 3.14;

    cout << a + b << endl;          // 5
    cout << a - b << endl;          // 1
    cout << a * b << endl;          // 6
    cout << pow(a, b) << endl;      // 9
    cout << a % b << endl;          // 1
    cout << a / b << endl;          // 1
    cout << pi / b << endl;         // 1.57
    cout << (double)a / b << endl;  // 1.5
}
Python
a = 3
b = 2
pi = 3.14

print(a + b)   # 5
print(a - b)   # 1
print(a * b)   # 6
# Pythonではべき乗は ** で表すことができます。
# 関数を自分で定義する必要はありません。
print(a ** b)  # 9
print(a % b)   # 1


# Pythonでは、除算は//と/で使い分けます。
# //は小数切り捨て除算、/は通常の除算です。
""" 割られる数が整数の場合、
//は商の整数部分を返し、
/は通常の演算で小数を返します。"""
print(a // b)  # 1
print(a / b)   # 1.5
""" 割られる数が小数の場合、
//は商の整数部分を小数で返し、
/は通常の除算で小数を返します。"""
print(pi // b) # 1.0
print(pi / b)  # 1.57

POINT

  • Pythonはintやdoubleなど、型宣言が不要です。
  • 文末の ;（セミコロン）も不要です。
  • Pythonの整数型はほかの言語と違い、どんなに大きな数値でも扱えます。これを任意精度整数や多倍長整数といいます。

Pythonの変数はC系の言語と違い、途中で全く違う型の値を入れることも可能です。 

x = 10
x = "hello"  # エラーにならない！

複数代入

Pythonでは、複数の変数にまとめて値を代入する便利な記法があります。

x, y = 1, 2
y, x = x, y  # xとyの値を入れ替える



真偽値（True / False）

条件が「正しい」か「正しくない」かを表す値を真偽値（boolean）といいます。 C++では true と false、Pythonでは True と False と書きます。Pythonでは先頭を大文字にすることに注意

C++
bool x = true;
bool y = false;

cout << x << endl;  // 1
cout << y << endl;  // 0

cout << (3 < 5) << endl;  // 1
cout << (3 == 5) << endl; // 0
Python
x = True
y = False

print(x)  # True
print(y)  # False

print(3 < 5)   # True
print(3 == 5)  # False

POINT

  • Pythonでは真偽値を True、False と先頭を大文字にして書きます。
  • C++では true、false とすべて小文字です。
  • Pythonの True と False は、C++の true と false に対応します。

文字列

文字や文章を扱うときは文字列を使います。 C++では string 型を明示しますが、Pythonでは型を宣言せずに文字列を代入できます。

C++
string name = "Alice";

cout << name << endl;

cout << name.size() << endl;  // 5
Python
name = "Alice"

print(name)

print(len(name))  # 5

Pythonでは、文字列同士を + でつなげることができます。 また、文字列の長さは組み込み関数 len() を使って取得できます。

C++
string first = "Hello";
string second = "World";

string message = first + " " + second;

cout << message << endl;       // Hello World
cout << message.size() << endl; // 11
Python
first = "Hello"
second = "World"

message = first + " " + second

print(message)       # Hello World
print(len(message))  # 11

POINT

  • Pythonでは文字列の型を str といいますが、変数を宣言するときに型を書く必要はありません。
  • 文字列は "Hello" や 'Hello' のように、" または ' で囲みます。
  • 文字列同士は + で結合できます。
  • 文字列の長さは len() で取得できます。
  • C++では string.size()、Pythonでは len(string) という違いがあります。

1.2 条件分岐・繰り返し

if / elif / else

Pythonのif文では、{}の代わりに、:(コロン)を用い字下げをします。実際に書く時には、:の後にEnterキーを押せば自動的に字下げが適用されるようになっています(VScodeやemacsの場合)。手動で行う場合、tabキー(Qキーの左にある)やスペースキーを押しましょう。

C++
if (x > 0) {
    cout << "positive" << endl;
} else if (x == 0) {
    cout << "zero" << endl;
} else {
    if (x < 10) {
        cout << "very negative" << endl;
    }
    else {
        cout << "negative" << endl;
    }
}
Python
if x > 0:
    print("positive")
elif x == 0:
    print("zero")
else:
    if x < 10:
        print("very negative")
    else:
        print("negative")

POINT

  • {} の代わりにインデント（字下げ）を使ってブロックを表します。
  • 条件式の () は不要ですが、行末に :（コロン）が必須です。
  • else if は elif と書きます。


forループ

Pythonのfor文は少し特殊で、拡張for文のような実装をされています。まずは拡張for文を復習しましょう。

拡張for文

C++
vector<int> a = {10, 20, 30, 40, 50};
for (int x : a) {
    cout << x << endl;
}
// 10
// 20
// 30
// 40
// 50
Python
a = [10, 20, 30, 40, 50]
for x in a:
    print(x)
# 10
# 20
# 30
# 40
# 50

このように、拡張for文は配列の要素を順々に取り出し、xに代入するような仕組みを持っています。毎回a[i]のように書く必要はありません。この拡張for文の仕組みが、Pythonのfor文の基礎となっています！

C++
for (int i = 0; i < 10; i++) {
    cout << i << endl;
}
Python
for i in range(10):
    print(i)

range(N) は、[0, 1, ..., N-1] の連続した数値の配列を返す関数です。これを拡張for文に適応しているという感じです。C++と違い、終了条件やインクリメント(i++)を直接書く必要はありません。

1.3 リスト

C++の 配列 や vector に相当するのが、Pythonの「リスト」です。

リストの基本操作

a = [10, 20, 30]

# 添字によるアクセス（C++と同じ）
print(a[0])    # 10 が出力される

# 要素の変更（C++と同じ）
a[0] = 100    # a =[100, 20, 30] になる

# 動的に要素を追加（C++の push_back に相当）
a.append(40)    # a =[100, 20, 30, 40] になる

#添え字によるアクセス (後ろから)
print(a[-1])    # 後ろから1番目の意味 40が出力される
print(a[-2])     # 後ろから2目の意味 30が出力される

添字を使ったアクセスはC++と全く同じですが、a[-1]などはPython独自の機能で、割と便利です。

スライス

Python独自の強力な機能が「スライス」です。a[開始:終了] と書くことで、リストの一部を簡単に切り出せます。（終了位置の要素は含まれません）。
range関数もrange(start, end) と記述すると、 [start, start+1, ..., end-1] を返します 

a = [10, 20, 30, 40, 50]

# インデックス1から3（4未満）までを取得
print(a[1:4])  # [20, 30, 40]
# インデックス0から2（3未満）までを取得
print(a[:3])   # [10, 20, 30] 最初が0の場合は省略できる
# 逆順に取得 (少し発展)
print(a[::-1])  # [50, 40, 30, 20, 10]

1.4 関数

関数の定義

C++
int add(int a, int b) {
    return a + b;
}

// 呼び出し
int result = add(3, 5);
Python
def add(a, b):
    return a + b

# 呼び出し
result = add(3, 5)

POINT

  • 関数の宣言には def を使います。
  • 戻り値の型（intなど）も、引数の型も記述する必要がありません。
  • if文などと同じく、末尾の : とブロックのインデントを忘れないようにしましょう。

引数や戻り値の型を指定する

Pythonでは、基本的に引数や戻り値の型を指定する必要はありません。 しかし、型ヒントを使うことで、型を明示的に記述することもできます。

C++
int add(int a, int b) {
    return a + b;
}
Python
def add(a: int, b: int) -> int:
    return a + b

引数の型は 引数名: 型、戻り値の型は -> 型 のように記述します。

POINT

  • 引数の型は a: int のように記述します。
  • 戻り値の型は -> int のように記述します。
  • これらは型ヒントと呼ばれ、C++の型指定とは異なり、型が違っても実行時に自動的にエラーになるわけではありません。

1.5 Pythonらしい記法

非常に強力なPythonならではの記法をいくつか紹介します。

リストには何でも入れられる

Pythonのリストには、同じ型のデータだけでなく、異なる型のデータを混ぜて入れることができます。Pythonの柔軟性や直感的に記述できる設計が表れていますね。 さらに、リストの中にリストを入れることもできます。

C++
vector<int> a = {1, 2, 3};

vector<string> b = {
    "apple", "banana"
};

// 型の違うデータを
// 1つのvectorには入れられない
Python
a = [1, "hoge", [1, 2, 3], True]

print(a[0])  # 1
print(a[1])  # hoge
print(a[2])  # [1, 2, 3]
print(a[3])  # True

POINT

  • Pythonのリストには、異なる型の値を混ぜて入れることができます。
  • リストの中に、さらにリストを入れることもできます。
  • ただし、ゲームなどでは同じ種類のデータをまとめて扱うため、同じ型の値を入れることも多いです。

in：リストの中を検索する

Pythonでは、in を使うことで、リストの中に特定の値が含まれているかを簡単に調べられます。 ゲームでは、アイテムを持っているか、特定の敵が存在するかなどを調べるときに利用できます。 

items = ["sword", "potion", "shield"]

if "potion" in items:
    print("回復アイテムを持っています")

if "bow" not in items:
    print("弓を持っていません")

辞書（dict）

Pythonには、キーと値を対応させてデータを管理する辞書（dict）があります。 C++の map や unordered_map に近いデータ構造です。 ゲームでは、プレイヤーのステータスやアイテムの情報などをまとめるのに便利です。

C++
map<string, int> status;

status["hp"] = 100;
status["attack"] = 20;

cout << status["hp"]
     << endl;
Python
status = {
    "hp": 100,
    "attack": 20
}

print(status["hp"])

Pythonの辞書は、値としてリストや別の辞書なども入れられます。 

player = {
    "name": "Alice",
    "hp": 100,
    "items": ["sword", "potion"],
    "position": [50, 80]
}

print(player["name"])      # Alice
print(player["items"][0])  # sword
print(player["position"])  # [50, 80]

リスト内包表記

既存のリストから新しいリストを作るとき、for 文を使った処理を 1行で簡潔に書くことができます。 特に、ゲーム内の敵や弾など、複数のオブジェクトをまとめて処理するときに便利です。

通常の書き方
enemies = []

for i in range(5):
    enemies.append(i * 20)
リスト内包表記
enemies = [i * 20 for i in range(5)]

ライブラリを使う

Pythonでは、他の人が作った機能をライブラリとして利用できます。 import を使うことで、そのライブラリの機能を自分のプログラムから利用できるようになります。

例えば、ゲームではランダムな値を生成したり、三角関数を使って物体を動かしたりすることがあります。 Pythonには、そのためのライブラリが標準で用意されています。 

import random
import math

# 1～6のランダムな整数
dice = random.randint(1, 6)
print(dice)

# 0～1のランダムな小数
x = random.random()
print(x)

# sinを計算する
y = math.sin(math.pi / 2)
print(y)  # 1.0

POINT

  • import を使うと、ライブラリの機能を利用できます。
  • random はランダムな値を生成するときに便利です。
  • math には sin()、cos()、sqrt() など、数学に関する機能があります。
  • Pyxelでも、こうしたライブラリと組み合わせてゲームを作ることができます。

ライブラリの機能を直接使う

import の書き方にはいくつかの方法があります。 よく使う機能だけを取り出して使うこともできます。

モジュール全体を読み込む
import math

print(math.sin(math.pi / 2))
関数だけを読み込む
from math import sin, pi

print(sin(pi / 2))

POINT

  • import math とすると、math.sin() のように機能を利用します。
  • from math import sin とすると、sin() と直接書けます。
  • Pyxelもライブラリの一つであり、import pyxel として利用します。
