Pyxelは「レトロゲームエンジン」として、 ドット絵ゲームに必要な基本機能が1つのライブラリとして コンパクトにまとまっています。 最初にPyxelの全体像を把握しておくと、 「こういうこともできそうだ」という発想につながります。

Pyxelには、四角形や円、線、三角形などを描画するための 基本的な図形描画APIが用意されています。 まずは「どのような図形が描けるのか」を把握しましょう。また、使用できる色の種類も確認しておきます。

6.1.2 主要な描画APIと使用できる色

API 描画対象 主な引数 用途

pyxel.cls(色) は画面を指定した色でクリアする関数です。 通常は draw() の先頭で毎フレーム呼び出します。

Python 
def draw(self):

    pyxel.cls(1)

    # ここからゲームオブジェクトを描画
    pyxel.rect(70, 50, 20, 20, 11)

6.1.5 描画APIを組み合わせる

基本図形を組み合わせるだけでも、 簡単なゲーム画面を構築できます。

Python 
import pyxel


class SimpleScene:

    def __init__(self):
        pyxel.init(160, 120, title="Drawing Combined")
        pyxel.run(self.update, self.draw)

    def update(self):
        pass

    def draw(self):
        # 1. 画面をクリア
        pyxel.cls(1)

        # 2. 背景の星
        pyxel.circ(20, 30, 1, 10)
        pyxel.circ(130, 20, 1, 10)

        # 3. プレイヤー
        pyxel.tri(
            80, 90,
            75, 100,
            85, 100,
            11
        )

        # 4. 敵
        pyxel.rect(76, 20, 8, 8, 8)

        # 5. スコア
        pyxel.text(4, 4, "SCORE: 00500", 7)

6.2 画像・スプライトを使ってみよう

ドット絵などの画像をゲーム画面へ表示するには、 PyxelのImage Bankと pyxel.blt() を使用します。

6.2.1 Pyxel Editor

Pyxelには、画像、タイルマップ、効果音、BGMなどを 編集できる専用ツール「Pyxel Editor」が用意されています。 作成したリソースは .pyxres ファイルとして保存できます。

6.2.2 Image Bank

Image Bankは、Pyxel内で画像を保持する領域です。 ゲーム実行時には、その画像領域から必要な部分を切り出して 画面へ描画します。

6.2.3 pyxel.blt()

Image Bankから画像を切り出して画面へ描画する関数が pyxel.blt() です。

pyxel.blt(x, y, img, u, v, w, h, [colkey])

【最重要】画面座標 (x, y) と画像座標 (u, v)

Image Bank

Sprite

(u, v)： 画像のどこから切り出すか

Game Screen

Sprite

(x, y)： 画面のどこへ描画するか

座標を混同しない

(x, y) はゲーム画面上の描画位置、 (u, v) はImage Bankから画像を切り出す位置です。 名前が似ていますが、役割はまったく異なります。

6.2.4 スプライト

ゲームにおけるスプライトとは、 キャラクター、敵、弾、アイテムなどを表す2D画像のことです。

5章では、Player や Enemy のようなクラスを作り、 それぞれのオブジェクトを管理しました。 今度は、その draw() の中で pyxel.blt() を使えば、 四角形ではなくドット絵をキャラクターとして表示できます。

5章とのつながり

Player
キャラクターの状態を管理
↓
draw()
キャラクターを描画
↓
pyxel.blt()
スプライトを表示

つまり、5章で作ったゲームの構造を変える必要はありません。 「どう描画するか」だけを変える ことで、ゲームをドット絵らしく発展させられます。

6.2.5 透明色

スプライトをそのまま四角形として描画すると、 画像の背景まで表示されてしまうことがあります。

そこで pyxel.blt() の最後の引数である colkey を使います。 colkey にカラーIDを指定すると、 その色を透明色として扱えます。

例えば colkey=0 とすると、 カラーID 0 の部分は画面に描画されません。 そのため、背景が透明なキャラクターのように表示できます。

Python 
pyxel.blt(
    self.x,
    self.y,
    0,
    0,
    0,
    16,
    16,
    0
)

今回の引数

引数 意味
self.x, self.y ゲーム画面上の描画位置
0 Image Bank 0 を使用
0, 0 Image Bank の (0, 0) から切り出す
16, 16 16 × 16 の範囲を切り出す
0 カラーID 0 を透明として扱う

ポイント： 透明色は「画像そのものを透明にする」のではなく、 指定したカラーIDの部分を描画しない、という仕組みです。

6.2.6 アニメーション

スプライト画像を1枚だけ表示するだけでなく、 複数の絵を順番に表示すると、キャラクターを動かすことができます。

例えば、Image Bankに 「歩いているキャラクター」の画像を4コマ並べておき、 u の値を変化させながら pyxel.blt() を呼び出します。

例えば、16×16のスプライトを横に4つ並べた場合、 切り出し位置を u = 0、 16、 32、 48 と変化させれば、4種類の絵を順番に表示できます。

Python 
import pyxel

frame = 0

def update():
    global frame

    frame = (frame + 1) % 4

def draw():
    pyxel.cls(0)

    pyxel.blt(
        70,
        50,
        0,
        frame * 16,
        0,
        16,
        16,
        0
    )

pyxel.init(160, 120)
pyxel.run(update, draw)

このコードのポイント

frame は、 現在何コマ目を表示するかを表す変数です。

frame * 16 によって、 Image Bank上の切り出し位置 u を 0 → 16 → 32 → 48 と変化させています。

% 4 は、 4で割った余りを求める演算です。 そのため frame は 0 → 1 → 2 → 3 → 0 → … と繰り返します。

アニメーションの考え方

アニメーションそのものを特別な機能として考える必要はありません。 「表示する画像を少しずつ切り替える」 ことで、動いているように見せています。

frame = 0
frame = 1
frame = 2
frame = 3

6.5.1 アニメーションの「魔法の式」を理解する

アニメーションでは、ゲーム開始からのフレーム数を利用して 表示するコマを切り替える方法がよく使われます。

frame = (pyxel.frame_count // 5) % 4
  • pyxel.frame_count： ゲーム開始からのフレーム数。
  • // 5： 5フレームごとに値を1増やす。
  • % 4： 0〜3の範囲で値を循環させる。
frame_count 0〜4 5〜9 10〜14 15〜19 20〜24
// 5 0 1 2 3 4
% 4 0 1 2 3 0

例えば1コマが16ピクセル幅なら、 u = frame * 16 とすることで、Image Bank上の画像を順番に切り替えられます。

6.5.3 ゲームの状態管理

ゲームには「タイトル」「プレイ中」「ゲームオーバー」などの 状態があります。状態を1つの変数で管理すると、 シーンの切り替えを整理できます。

Python 
import pyxel


class GameMaster:

    def __init__(self):
        self.state = "TITLE"

    def update(self):

        if self.state == "TITLE":

            if pyxel.btnp(pyxel.KEY_RETURN):
                self.state = "PLAYING"

        elif self.state == "PLAYING":

            # ゲーム本体の更新処理
            pass

        elif self.state == "GAMEOVER":

            if pyxel.btnp(pyxel.KEY_RETURN):
                self.state = "TITLE"

    def draw(self):

        pyxel.cls(0)

        if self.state == "TITLE":

            pyxel.text(
                50,
                55,
                "PRESS ENTER",
                7
            )

        elif self.state == "PLAYING":

            # プレイヤーや敵を描画
            pass

        elif self.state == "GAMEOVER":

            pyxel.text(
                60,
                55,
                "GAME OVER",
                8
            )
