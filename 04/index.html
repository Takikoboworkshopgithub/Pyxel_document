4.0 Pyxel

Pyxelとは

Pyxel（ピクセル）は、Pythonでゲームを作るためのライブラリです。特に、ドット絵を使ったレトロゲーム風の2Dゲームを簡単に作れるように設計されています。

【ゲームエンジン】

ゲームを作る際に必要になる、グラフィックの描画、キーボード入力の受け取り、音声の再生、ゲーム全体の進行管理（ゲームループ）などの機能をまとめて提供する仕組みのことです。

Pyxelも立派なゲームエンジンの一つです。機能が非常にシンプルにまとまっているため、学習教材として扱いやすく、ゲームプログラムの基本構造を理解するのに最適です。

他のゲームエンジンとの比較

世の中には様々なゲームエンジンが存在します。今回の教材ではなぜPyxelを使うのか、表と図で比較してみましょう。

エンジン 主な言語 2D/3D 学習コスト 今回の教材との相性
Pyxel Python 2D 非常に低い ◎ (基本構造を学ぶのに最適)
Unity C# 2D/3D 高い △ (多機能すぎて初学者は迷子になりがち)
Godot GDScript / C# 2D/3D 中程度 〇 (本格的なゲーム制作向け)
Unreal Engine C++ / Blueprint 3D中心 非常に高い △ (高度なグラフィック向け)

今回は「高度な機能を使うこと」よりも、「ゲームの基本構造（裏側の仕組み）を理解すること」を優先するため、最もシンプルでコードの全体像が見えやすいPyxelを採用します。

4.1 コーディング

ここからは実際にPythonのファイルを作成し、コードを書いていきましょう。main.py などのファイルを作成して進めてください。

Step 1：Pyxelを読み込む

まず、Pyxelの機能を利用するためにモジュールを読み込みます。
import はC言語でいう、#include<stdio.h>のようなものです。

Python
import pyxel

Step 2：画面を初期化する

次に、ゲームの画面を作ります。
pyxel.init(width, height) は、指定した幅と高さでゲーム画面などの初期設定を行うためのPyxelの関数です。

Python
import pyxel

# 画面の幅を160、高さを120に設定して初期化
pyxel.init(160, 120)

Step 3：update()とdraw()を用意する

Pyxelを動かすには、特別な2つの関数 update と draw が必要です。
（def は第1章で学んだ関数を定義する構文です。）

Python
import pyxel

def update():
    pass

def draw():
    pass

pyxel.init(160, 120)

pass とは？
Pythonにおいて「ここでは何もしない」という処理を書くための文です。中身が空の関数を作るとエラーになるため、一時的に置いています。

Step 4：ゲームを動かす

最後に、pyxel.run() を使ってゲームを起動します。
pyxel.run(update, draw) は、先ほど定義した2つの関数をPyxelに渡し、「この2つの処理をゲーム中にずっと繰り返し呼び出してね」とお願いする関数です。

Python
import pyxel

def update():
    pass

def draw():
    pass

pyxel.init(160, 120)
pyxel.run(update, draw)

実行してみよう

ターミナルで python main.py（またはファイル名）を実行してください。

何が起こった？
画面は開きますが、真っ暗なままで何も表示されません。
なぜ何も描画されないのでしょうか？ その答えと仕組みを次の 4.2 で解説します。

4.2 ゲームループ

ゲームは、プログラムが上から下へ1回だけ実行されて終わるわけではありません。
ゲームが起動している間、プログラムは「入力を受け取る → 状態を変える → 画面を描画する」という処理を猛烈なスピードで何度も何度も繰り返しています。
この繰り返しの仕組みを「ゲームループ」と呼びます。

ゲームループとは

pyxel.run(update, draw) は、まさにこのループ処理を開始する合図だったのです。
それぞれの関数がどんな役割（責務）を持っているか見てみましょう。

update() の役割

ゲーム内部の「状態」を更新する関数

  • キー入力を受け取る
  • プレイヤーや敵の座標を変える
  • HPやスコアを変更する
  • 当たり判定を行う

draw() の役割

現在のゲームの「状態」を画面に描画する関数

  • プレイヤーを描く
  • 敵や背景を描く
  • 文字（スコア等）を表示する

update()とdraw()を実験する

本当にこの2つの関数が何度も呼ばれているのか、print() を使って実験してみましょう。

Python
import pyxel

def update():
    print("update")

def draw():
    print("draw")

pyxel.init(160, 120)
pyxel.run(update, draw)

※ 実行するとターミナルに大量の文字が表示され続けます。確認できたら Ctrl + C でプログラムを強制終了してください。
これはあくまで仕組みを確認するための実験用コードです。実際のゲーム制作では update や draw の中で print を多用するとゲームが重くなる原因になります。

draw()で四角形を描く

それでは、画面に実際にものを描画してみましょう。

Python
import pyxel

def update():
    pass

def draw():
    # ① 画面全体を色0(黒)で塗りつぶす
    pyxel.cls(0)

    # ② x=70, y=50 の位置に 幅20, 高さ20 の 色7(白) の四角形を描く
    pyxel.rect(70, 50, 20, 20, 7)

pyxel.init(160, 120)
pyxel.run(update, draw)

▶ 実行するとどうなる？

黒い画面の中央付近に、白い四角形が表示されます。

⚠️ 注意：pyxel.cls() の cls は class ではありません！

pyxel.cls() は Clear Screen（画面クリア）の略であり、画面全体を指定した色で塗りつぶすPyxelの関数です。第2章で学んだ Python の class（クラス）とは全く無関係ですので、絶対に混同しないでください。

なぜ draw() の最初に cls() を呼ぶのか？

ゲームは毎フレーム新しく絵を描き直します。もし最初に画面をクリア（塗りつぶし）しないと、前のフレームで描いた絵がそのまま画面に残ってしまい、残像だらけになってしまうからです。

xをゲームの状態にする

現在は 70 という固定の数値を描画しています。これを動かすために、ゲームの状態（State）として変数 x に置き換えてみましょう。

【ゲームの状態】 その時点でゲームが持っている情報のこと。ここでは四角形のx座標が状態の一部になります。

Python
import pyxel

x = 70  # 四角形の現在位置(状態)

def update():
    pass

def draw():
    pyxel.cls(0)
    # 固定の 70 ではなく、変数 x の位置に描く
    pyxel.rect(x, 50, 20, 20, 7)

pyxel.init(160, 120)
pyxel.run(update, draw)

update()で状態を変える

状態 x を準備できたので、いよいよ update() の中でこの状態を変化させましょう。

Python
import pyxel

x = 70

def update():
    global x  # 関数の外にある変数 x を変更するために必要
    x += 1    # 毎フレーム x を 1 ずつ増やす

def draw():
    pyxel.cls(0)
    pyxel.rect(x, 50, 20, 20, 7)

pyxel.init(160, 120)
pyxel.run(update, draw)

▶ 実行するとどうなる？

四角形が右方向へスーッと移動していきます。
（画面外に出てもエラーにはならず、そのまま消えていきます）

ここで初めて出てきた global はPythonの機能です。関数の外側で定義された変数 x を、関数 update() の内部で変更（上書き）するために宣言しています。

このプログラムが動く仕組みを図で見てみましょう。

updateとdrawを分離する理由

初心者によくある間違いとして、draw() の中で x += 1 をしてしまうことがあります。
しかし、設計上これは悪い例です。

✕ 悪い例 (混在させる)

def draw():
  global x
  x += 1
  pyxel.rect(x...)

描画と状態変更が混ざると、後からプログラムが複雑になった時にバグの原因になります。

〇 良い例 (責務を分離する)

  • update()
    → ゲームの状態を変更する
  • draw()
    → 現在の状態を描画する

役割（責務）をきっちり分けることで、プログラムが読みやすく安全になります。

Q. 確認問題：次のコードでは、四角形はどちらに移動するでしょう？ 
x = 70
def update():
    global x
    x -= 1
  • A. 右
  • B. 左
  • C. 上
  • D. 動かない

正解：B. 左

理由：x -= 1 は x の値を毎フレーム減らします。数学のグラフと同じように、x座標が減ると左方向へ移動します。

4.3 座標と描画

Pyxelの座標系 (x, y)

Pyxel（および多くのゲームエンジン）の2D座標系は、数学の授業で習うグラフとはy軸の向きが異なります。
左上が原点 (0, 0) となり、右に行くほど x が増え、下に行くほど y が増えます。

pyxel.rect()

先ほど使った四角形を描く関数の引数を詳しく見てみましょう。
pyxel.rect(x, y, width, height, color)

  • x：四角形の左上のx座標
  • y：四角形の左上のy座標
  • width：幅（横の長さ）
  • height：高さ（縦の長さ）
  • color：色（0〜15の数字で指定。0は黒、7は白など）

pyxel.text()

画面に文字を表示する関数もあります。
pyxel.text(x, y, text, color)
これを利用して、ゲームの状態（変数）を画面に表示させることができます。

Python
# draw() の中に書く例
def draw():
    pyxel.cls(0)
    # 単純な文字を表示
    pyxel.text(10, 10, "Hello Pyxel!", 7)

    # f文字列(第1章で学習)を使って、変数xの現在値を表示
    pyxel.text(10, 20, f"x = {x}", 7)

4.4 キーボード入力

pyxel.btn()

プレイヤーがキーボードを押したかどうかを判定するには、pyxel.btn() 関数を使用します。
指定したキーが現在押されていれば True、押されていなければ False を返します。

【True / False】 真（正しい）か偽（正しくない）かを表すPythonの特別な値（真理値）です。

  • pyxel.btn(pyxel.KEY_LEFT) : 左矢印キー
  • pyxel.btn(pyxel.KEY_RIGHT) : 右矢印キー
  • pyxel.btn(pyxel.KEY_UP) : 上矢印キー
  • pyxel.btn(pyxel.KEY_DOWN) : 下矢印キー

ifとの組み合わせ

「もしキーが押されていたら、状態を変更する」という処理は、第1章で学んだ if 文と組み合わせることで実現します。

Python
# update() の中に書く例
def update():
    global x

    # 【Python】 if文
    # 【Pyxel】 pyxel.btn()
    if pyxel.btn(pyxel.KEY_LEFT):
        x -= 1   # 左キーが押されていれば、xを減らす

左右・上下の移動

右移動、上移動、下移動も同様に追加できます。
先ほどの座標系（下に行くほど y が増える）を思い出してください。

Python
def update():
    global x, y

    if pyxel.btn(pyxel.KEY_LEFT):
        x -= 1
    if pyxel.btn(pyxel.KEY_RIGHT):
        x += 1
        
    if pyxel.btn(pyxel.KEY_UP):
        y -= 1
    if pyxel.btn(pyxel.KEY_DOWN):
        y += 1

Step 6：Gameクラスにまとめる (最終コード)

これまでは global x, y を使って状態を管理していましたが、本格的なゲームを作ろうとすると変数が無数に増えて破綻してしまいます。
そこで、第2・3章で学んだクラスの出番です。「ゲーム本体」を1つのクラスとして設計し、self.x のようにオブジェクトの属性（状態）として持たせます。

Python
import pyxel

# 【Python】 第2章で学んだクラスの定義
class Game:
    def __init__(self):
        # self.x, self.y がこのゲーム(オブジェクト)の状態
        self.x = 70
        self.y = 50

    # 【Python】 selfを持つメソッド
    def update(self):
        # 【Pyxel】 キー入力判定
        if pyxel.btn(pyxel.KEY_LEFT):
            self.x -= 1
        if pyxel.btn(pyxel.KEY_RIGHT):
            self.x += 1
        if pyxel.btn(pyxel.KEY_UP):
            self.y -= 1
        if pyxel.btn(pyxel.KEY_DOWN):
            self.y += 1

    def draw(self):
        # 【Pyxel】 描画処理
        pyxel.cls(0)
        pyxel.rect(self.x, self.y, 10, 10, 7)

# 【Python】 Gameクラスのインスタンス（オブジェクト）を作成
game = Game()

# 【Pyxel】 Pyxelの初期化
pyxel.init(160, 120)

# 【Pyxel/Python】 gameオブジェクトのメソッドをPyxelに渡してループ開始
pyxel.run(game.update, game.draw)

▶ 実行するとどうなる？

矢印キーを使って、白い四角形を上下左右に自由に動かすことができます。
※現状は画面外に出ることも可能ですし、敵や当たり判定などはまだ存在しません。

最終コードのポイント

  • class Game: と __init__ を使って、ゲーム全体の初期状態（x, y）を準備しています。
  • global を使わなくても、self.x self.y によってクラス内のどこからでも安全に状態を変更・読み取りできるようになりました。
  • pyxel.run(game.update, game.draw) は、「関数を呼び出している」というより、「作成した game オブジェクトの update メソッドと draw メソッドを、Pyxelのループ機能にお任せ（渡している）」という意味になります。
Q. 確認問題：次のうち、Pyxelの機能ではなく Python標準の機能（構文）であるものはどれ？
  • A. pyxel.init()
  • B. class Game:
  • C. pyxel.rect()
  • D. pyxel.btn()

正解：B. class Game:

理由：クラス（class）はPythonという言語自体の基本機能です。A, C, Dはすべて、ゲームを作るためにPyxelが提供している専用の関数です。この「Pythonの機能」と「Pyxelの機能」の区別がつくようになることが、上達の第一歩です。

この章で学んだこと

  • Pyxel / ゲームエンジン：描画や入力を簡単に扱えるようにする仕組み。
  • pyxel.init()：ゲーム画面を準備する。
  • pyxel.run()：ゲームループを開始する。
  • ゲームループの基本構造：
    • ① 入力 を受け取る
    • ② update() でゲームの状態を変える
    • ③ draw() で現在の状態を画面に描く
  • 座標系：左上が (0, 0)。右へ行くと x が増え、下へ行くと y が増える。
  • pyxel.cls()：画面を塗りつぶしてクリアする。classとは無関係。
  • pyxel.rect() / pyxel.text()：四角形や文字を描画する。
  • pyxel.btn()：キーボードの入力状態（True/False）を調べる。
  • クラスとの融合：変数が増えても破綻しないように、ゲーム全体を Game クラスとして設計する。
